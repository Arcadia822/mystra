# Architecture Design (系统架构方案) 模板包

适用于系统技术选型、微服务拓扑、基础设施规划、数据管道设计的场景。

## 场景定位
- **目标**：清晰展示系统全貌、组件关系、数据流动路径、核心权衡与备选方案。
- **推荐主入口**：`overview.md`。

## 导航推荐结构
1. **系统全貌 (Overview)**：系统背景、核心指标与高层架构图（Mermaid）。
2. **数据流与模型 (Data Flow)**：数据实体流动、存储与生命周期。
3. **技术权衡 (Tradeoffs)**：选型考量与未选方案原因。

## 包含文件
- `template.md`: 架构设计通用骨架。
- `bundle.json`: 预设分组的最小化架构文档 bundle。
- `empty.taco.html`: 开箱即用的空白架构 Taco，支持离线预览 Mermaid。
