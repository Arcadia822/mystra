# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-05-09

### Added

- Control plane with job CRUD, runner registration, long-poll job claim, and MCP endpoint.
- Pull-based runner daemon with heartbeat and Docker task container execution.
- Codex CLI and GitHub Copilot CLI agent adapters.
- GitLab branch push and merge request delivery.
- Structured lifecycle events and run results.
- Deterministic test-then-build quality gate.
- In-memory local store for development.
- 5xP project context documents and Spec-Kit integration.
