Runtimes

Runtime 是可提供计算能力的执行后端。在一台已装 agent CLI 的机器上启动 mystra-runner 即纳管为 host Runtime；runner 自动发现并确认可用 Provider，持续回报心跳。 （发起任务 / Context / Agent 配置不在本 feature 范围）

Add a computerMVP 无 pairing / 无校验

在目标机器上安装并以指定 endpoint 启动 mystra-runner。配好 endpoint 直接启动即完成注册。 假定该机器上目标 agent CLI 已安装并已登录。

1
安装 runner（TypeScript）
npm i -g @mystra/runner   # 或 pnpm dlx @mystra/runner
2
配置 control-plane endpoint 并启动
mystra-runner --endpoint https://mystra.local/api \
              --name "$(hostname)"
3
（可选）覆盖某个 Provider 的可执行路径
MYSTRA_COPILOT_PATH=/opt/bin/copilot mystra-runner --endpoint ...
启动后本页 Runtimes 列表会出现该机器；runner 会自动发现 PATH 上受支持的 agent CLI、 确认可用性，并持续回报心跳。运行期新装 CLI 无需重启。
