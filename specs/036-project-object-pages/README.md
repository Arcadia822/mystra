# 036 Project Object Pages

本功能把既有 Project API/CLI 投影到 Control Plane Web UI，并从 Tasks 删除通用
Issue dispatch 面板。Issues 与 provider-specific Integrations 明确延期。

- `spec.md`: 用户旅程、需求与范围
- `plan.md`: 架构、工程审查与验证
- `contracts/object-surfaces.md`: Web/API/CLI 同源契约
- `tasks.md`: 实施清单
- `quickstart.md`: CLI 与浏览器验收
